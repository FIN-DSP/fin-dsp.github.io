Got an audio project? Get it listed.

FIN-DSP lists new audio software projects as they appear — plugins, DSP, synthesizers, effects, audio engines, DAWs, libraries, frameworks, and tools.

To get your project listed, open an issue on the FIN-DSP org on GitHub with your repository link. The automated discovery engine is in development and will find new audio projects on GitHub and list them here.
